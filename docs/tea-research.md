> Дата сбора: 2026-07-11

## 1. Формат данных на сайте

### Файлы проекта

| Файл | Назначение |
|------|-----------|
| `types/tea.ts` | TypeScript-интерфейсы |
| `data/teas.json` | Каталог чаёв (единственный источник данных) |
| `public/teas/` | Фотографии чаёв (`/{slug}.jpg`) |
| `lib/teas.ts` | Доступ к данным, фильтрация, лейблы |

### Типы чая (`TeaType`)

```
green | black | oolong | pu-erh | white | yellow
```

### Способы заваривания (`BrewMethodType`)

```
gongfu | western | grandpa | cold-brew | iced
```

### Обязательные поля записи `Tea`

```typescript
{
  id: string;                    // уникальный ID (следующий после последнего в teas.json)
  slug: string;                  // URL: /{slug}, латиница, kebab-case
  name: string;                  // русское название
  photo?: string;                // "/teas/{slug}.jpg"
  description?: string;          // 1-3 предложения
  type: TeaType;
  primaryBrewMethod: BrewMethodType;
  brewMethods: BrewMethod[];     // минимум 1
  characteristics: {
    aroma: string[];             // обязательно
    flavor: string[];            // обязательно
    aftertaste: string[];        // обязательно
    appearance?: string[];
    liquorColor?: string;        // hex, например "#E6D7A8"
  };
  meta: {
    origin?: string;
    altitude?: number;           // метры
    harvestDate?: string;        // ISO: "2024-04-15"
    rating: number;              // 1.0–5.0
    favorite: boolean;           // всегда false для новых
    addedDate: string;           // ISO: "2026-07-11"
  };
}
```

### Поля `BrewMethod`

```typescript
{
  id: string;                    // "{type}-{teaId}", напр. "gongfu-3"
  name: string;                  // "Гунфу-ча", "Западный стиль"
  type: BrewMethodType;
  description: string;
  ratio: number;                 // грамм чая на 100 мл воды
  temperature: { from: number; to: number };  // °C
  infusions: {
    number: number;
    time: number;                // секунды
    notes?: string;
  }[];
  notes?: string[];
}
```

### Существующие записи (не дублировать)

| slug | name | type |
|------|------|------|
| `longjing` | Лунцзин | green |
| `assam` | Ассам | black |

### Соглашения по стилю (из существующих записей)

- Описания на русском, живым языком
- Аромат/вкус/послевкусие — короткие теги с заглавной буквы: `"Каштан"`, `"Солодовый"`
- `liquorColor` — hex-цвет настоя
- Для китайских чаёв указывать регион происхождения в `meta.origin`
- `rating` — оценка 4.0–4.8 для известных сортов
- Гунфу-ча — основной метод для китайских зелёных, улунов, пуэров
- Западный стиль — для чёрных чаёв (Ассам, Дарджилинг, Цейлон)

## 3. Классификация чая

Источники: [Википедия — Чай](https://ru.wikipedia.org/wiki/Чай), [Tasty Coffee — сорта чая](https://shop.tastycoffee.ru/blog/sorta-chaya), [Orientaleaf — 6 видов](https://orientaleaf.com/ru/blogs/tea-101/6-types-of-chinese-tea), [Laomars — китайский чай](https://laomars.com/ru/blog/kitayskiy-chay-osnovy-i-klassifikatsiya/)

Все чаи производятся из **Camellia sinensis**. Классификация по степени ферментации (окисления):

| Тип | Кит. название | Окисление | Обработка | Профиль вкуса |
|-----|--------------|-----------|-----------|---------------|
| Зелёный | 绿茶 (Лу Ча) | 0–5% | Обжиг/пар (杀青) | Свежий, растительный, ореховый, бобовый |
| Белый | 白茶 (Бай Ча) | 5–15% | Увядание и сушка | Нежный, цветочный, медовый |
| Жёлтый | 黄茶 (Хуан Ча) | 10–20% | Запечатанное пожелтение (闷黄) | Мягкий, гладкий, сладкий |
| Улун | 乌龙茶 (Улун) | 15–80% | Прокатка и окисление | От цветочных до жареных и фруктовых |
| Чёрный (красный) | 红茶 (Хун Ча) | 100% | Полное окисление | Солодовый, сладкий, шоколадный |
| Пуэр (тёмный) | 普洱茶 (Пуэр) | Постферментация | Естественная или ускоренная | Землистый, древесный, сладкий (шу) / терпкий (шэн) |

**Важно:** травяные настои (иван-чай, ройбуш, каркаде, мате) — НЕ чай в ботаническом смысле. В каталог Justea не включать.

### Два вида чайного куста

- **Camellia sinensis var. sinensis** — китайский (мелколистный), зелёные, белые, улуны
- **Camellia sinensis var. assamica** — ассамский (крупнолистный), чёрные чаи Индии, пуэры Юньнаня

## 5. Кандидаты для добавления в каталог

Приоритет: популярные, узнаваемые сорта с хорошим покрытием в источниках.

### Приоритет 1 — must have

#### 3. Те Гуань Инь (`tie-guan-yin`)

- **Тип:** oolong
- **Происхождение:** Уезд Аньси, провинция Фуцзянь, Китай
- **Описание:** Светлый улун с ферментацией ~25%. Название — «Железная богиня милосердия». Один из самых известных китайских чаёв.
- **Аромат:** Орхидея, Сирень, Цветочный, Мёд
- **Вкус:** Сладкий, Сливочный, Цветочный, Фруктовый
- **Послевкусие:** Сладкое, Длительное, Медовое
- **Внешний вид:** Плотно скрученные тёмно-зелёные шарики
- **Цвет настоя:** #F5E6C8 (медово-прозрачный)
- **Заваривание:** гунфу, ratio 4.5, 85–95°C, проливы 20/15/20/25/30 сек, 6–8 проливов
- **Источники:** #11, #12, #13, #15

#### 4. Да Хун Пао (`da-hong-pao`)

- **Тип:** oolong
- **Происхождение:** Горы Уишань, провинция Фуцзянь, Китай
- **Описание:** Легендарный «утёсный» улун с сильной ферментацией. Характерная минеральность (янь юнь) благодаря каменистым склонам Уишань.
- **Аромат:** Древесный, Пряный, Жареный, Тёмный шоколад
- **Вкус:** Минеральный, Карамельный, Ореховый, Дымный
- **Послевкусие:** Длительное, Сладкое, Согревающее
- **Внешний вид:** Тёмные, скрученные листья с красноватым оттенком
- **Цвет настоя:** #C4622D (тёмно-янтарный)
- **Заваривание:** гунфу, ratio 5.0, 95–100°C, проливы 15/15/20/25/30/40 сек
- **Источники:** #11, #12, #13, #15

#### 5. Би Ло Чунь (`bi-lo-chun`)

- **Тип:** green
- **Происхождение:** Озеро Тайху, горы Дунтиншань, провинция Цзянсу, Китай
- **Описание:** «Изумрудная спираль весны» — зелёный чай с уникальным плодовым ароматом, который чай приобретает благодаря соседству с фруктовыми деревьями.
- **Аромат:** Фруктовый, Цветочный, Свежий, Персиковый
- **Вкус:** Нежный, Сладкий, Фруктовый, Лёгкая овощность
- **Послевкусие:** Сладкое, Чистое, Освежающее
- **Внешний вид:** Мелкие спиралевидные листья, изумрудно-зелёные
- **Цвет настоя:** #D4E7A0 (светло-зелёный)
- **Заваривание:** гунфу, ratio 3.5, 75–80°C, проливы 20/15/20/25 сек
- **Источники:** #4, #11, #17

#### 6. Бай Хао Инь Чжэнь (`bai-hao-yin-zhen`)

- **Тип:** white
- **Происхождение:** Уезд Фудин, провинция Фуцзянь, Китай
- **Описание:** «Серебряные иглы» — вершина белых чаёв. Изготавливается только из нераспустившихся почек, покрытых белым ворсом. Собирают 2–3 дня в году.
- **Аромат:** Цветочный, Медовый, Дынный, Нежный
- **Вкус:** Сладкий, Шелковистый, Дынно-абрикосовый, Лёгкая кислинка
- **Послевкусие:** Длительное, Цветочное, Чистое
- **Внешний вид:** Серебристые игольчатые почки с белым ворсом
- **Цвет настоя:** #F5F0DC (бледно-жёлтый, прозрачный)
- **Заваривание:** гунфу, ratio 5.0, 80–85°C, проливы 30/25/30/40/50 сек
- **Источники:** #3, #10, #16, #21

#### 7. Сенча (`sencha`)

- **Тип:** green
- **Происхождение:** Япония (регионы: Сидзуока, Кагошима, Удзи)
- **Описание:** Самый популярный японский зелёный чай. Листья обрабатываются паром (в отличие от китайских зелёных с обжигом), что даёт характерный «зелёный» профиль.
- **Аромат:** Свежая трава, Морские водоросли, Хвойный, Зелёный
- **Вкус:** Освежающий, Умами, Травянистый, Лёгкая горчинка
- **Послевкусие:** Чистое, Свежее, Лёгкое
- **Внешний вид:** Тонкие игольчатые листья тёмно-зелёного цвета
- **Цвет настоя:** #C5D86D (ярко-зелёный)
- **Заваривание:** западный, ratio 2.0, 70–80°C, 120 сек; или гунфу ratio 4.0, 75°C, 20/15/20 сек
- **Источники:** #1, #12

#### 8. Дарджилинг (`darjeeling`)

- **Тип:** black
- **Происхождение:** Дарджилинг, Западная Бенгалия, Индия (Гималаи, 600–2000 м)
- **Описание:** «Шампанское среди чаёв». Первый сбор (first flush) — лёгкий мускатно-цветочный; второй (second flush) — плотный с виноградными нотами.
- **Аромат:** Мускат, Цветочный, Цитрусовый, Виноградный
- **Вкус:** Лёгкий, Цветочный, Фруктовый, Лёгкая терпкость
- **Послевкусие:** Длительное, Освежающее, Мускатное
- **Внешний вид:** Мелкие тёмные листья с золотистыми типсами
- **Цвет настоя:** #D4A76A (светло-янтарный)
- **Заваривание:** западный, ratio 2.5, 85–90°C, 180 сек
- **Источники:** #1, #12

### Приоритет 2 — расширение каталога

#### 9. Кимун (`keemun`)

- **Тип:** black
- **Происхождение:** Провинция Аньхой, Китай (уезды Цимэнь, Шитай)
- **Аромат:** Орхидея, Мёд, Вино, Фруктовый
- **Вкус:** Сложный, Цветочный, Медовый, Пряно-древесный
- **Послевкусие:** Длительное, Винное
- **Источники:** #18

#### 10. Хуаншань Маофэн (`huangshan-maofeng`)

- **Тип:** green
- **Происхождение:** Жёлтые горы, провинция Аньхой, Китай (700–800 м)
- **Аромат:** Свежий, Цветочный, Бамбуковый
- **Вкус:** Нежный, Сладкий, Освежающий
- **Послевкусие:** Сладкое, Чистое
- **Источники:** #20

#### 11. Шоу Мэй (`shou-mei`)

- **Тип:** white
- **Происхождение:** Уезд Фудин, провинция Фуцзянь, Китай
- **Описание:** «Брови старца» — белый чай из зрелых листьев и стеблей. Более насыщенный, чем Бай Хао Инь Чжэнь. Хорошо подходит для выдержки.
- **Аромат:** Сухофрукты, Травянистый, Древесный
- **Вкус:** Насыщенный, Сладкий, Древесно-травянистый
- **Послевкусие:** Длительное, Мягкое
- **Источники:** #10

#### 12. Шэн пуэр (`sheng-pu-erh`)

- **Тип:** pu-erh
- **Происхождение:** Провинция Юньнань, Китай
- **Описание:** «Сырой» пуэр — зелёный чай, который со временем естественно ферментируется. Молодой — терпкий и свежий, выдержанный — глубокий и сладкий.
- **Аромат:** Свежий, Травянистый, Цветочный (молодой); Древесный, Сухофрукты (выдержанный)
- **Вкус:** Терпкий, Свежий, Фруктовый (молодой); Глубокий, Сладкий, Землистый (выдержанный)
- **Послевкусие:** Длительное, Сладкое (выдержанный)
- **Источники:** #11, #22

#### 13. Шу пуэр (`shu-pu-erh`)

- **Тип:** pu-erh
- **Происхождение:** Провинция Юньнань, Китай
- **Описание:** «Зрелый» пуэр — прошёл ускоренную постферментацию (wo dui). Тёмный, гладкий, землистый.
- **Аромат:** Землистый, Древесный, Грибной
- **Вкус:** Гладкий, Сладкий, Землистый, Древесный
- **Послевкусие:** Сладкое, Тёплое, Успокаивающее
- **Источники:** #11, #22

#### 14. Цейлон (`ceylon`)

- **Тип:** black
- **Происхождение:** Шри-Ланка (регионы: Нувара-Элия, Ува, Димбула)
- **Аромат:** Цитрусовый, Пряный, Лёгкий
- **Вкус:** Яркий, Крепкий, Цитрусовый, Лёгкая терпкость
- **Послевкусие:** Освежающее, Чистое
- **Источники:** #2

#### 15. Дун Дин (`dong-ding`)

- **Тип:** oolong
- **Происхождение:** Гора Дун Дин (Морозный пик), Тайвань
- **Аромат:** Мёд, Жареный, Цветочный
- **Вкус:** Маслянистый, Медовый, Печёный, Сливочный
- **Послевкусие:** Длительное, Сладкое
- **Источники:** #3, #8

#### 16. Габа улун (`gaba-oolong`)

- **Тип:** oolong
- **Происхождение:** Тайвань; система высокогорных чаёв Алишань — один из районов производства
- **Описание:** Улун, прошедший бескислородную (анаэробную) обработку: лист завяливают сутки, затем помещают в вакуум и закачивают азот, и ферментация идёт без кислорода. Габа-чай — это **способ обработки, а не сорт**: так можно обработать зелёный чай, улун, Цзинь Сюань, Те Гуань Инь.
- **Аромат:** Особый чайный аромат (описание уровня A); «тёмные ягоды, сушёные травы, крыжовник» — из карточки магазина, уровень C
- **Вкус:** Слегка сладковатый с лёгкой терпкостью, настой более густого цвета
- **Послевкусие:** Сладкое
- **Источники:** #19 (уровень C) — факты выше по Минсельхозу Тайваня и Tsushida & Murai 1987, см. `docs/sources/raw/tw-gaba-tea.md`

> **Что убрано и почему.** Число «>150 мг ГАМК/100 г» стояло без источника: страница
> Минсельхоза Тайваня выгружена целиком, такой фразы там нет (разбор —
> `docs/sources/raw/tw-gaba-tea.md`). Утверждения «успокаивающий эффект» и
> «успокаивающее послевкусие» убраны по решению пользователя: о действии чая на
> человека в текстах не пишем.

## 6. Инструкции для второго агента

### Задача

Добавить чаи из раздела 5 в `data/teas.json` по формату из раздела 1.

### Алгоритм работы

1. Прочитать `data/teas.json` — определить последний `id`
2. Для каждого чая из приоритета 1:
   - Проверить, что `slug` не занят
   - Собрать/уточнить данные из указанных источников (раздел 4)
   - Сформировать JSON-запись по шаблону
   - Добавить `brewMethods` по справочнику (раздел 2)
   - Установить `meta.addedDate` = текущая дата
   - Установить `meta.favorite` = false
3. Добавить записи в `data/teas.json`
4. Фото: пока оставить `photo` пустым или использовать placeholder — реальные фото нужно будет добавить отдельно
