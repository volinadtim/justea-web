1. Яндекс Вордстат (wordstat.yandex.ru и API Вордстата): частотность, динамика, сезонность и регионы по запросам о чае. Темы: сорта, «как заваривать X», посуда, чайные церемонии (Москва и город пользователя — уточни у оркестратора). Если нужен вход в аккаунт пользователя, попроси оркестратора.

4. Составь семантическое ядро на русском: кластеры запросов, интент (инфо/коммерция/локальный), частотность, конкуренция, предложенная посадочная страница. Отдельно — кластер «чайная церемония» для лендинга Регины.
