## JSON (машиночитаемый)

См. полный массив в ответе агента или используйте поля выше для генерации `teas.json`.

При импорте:
- `primaryBrewMethod: "western"` → ratio 2.5, 95°C, 180 сек (см. `docs/tea-research.md` §2)
- `primaryBrewMethod: "gongfu"` → ratio 4.0–4.5, 85–95°C, короткие проливы
- `meta.favorite: false`, `meta.addedDate` = дата импорта
- `liquorColor`: чёрные `#D4A76A`–`#8B4513`, зелёные `#C5D86D`–`#D4E7A0`, улуны `#F5E6C8`
