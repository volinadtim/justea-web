## Инструкции для импорта

1. Выбрать чаи по приоритету (сначала P2, затем P3)
2. Проверить, что `slug` не занят в `data/teas.json`
3. Сформировать полную запись по шаблону из `docs/tea-research.md` (раздел 6)
4. Добавить `brewMethods` по справочнику (раздел 2)
5. Установить `meta.addedDate`, `meta.favorite: false`, `rating` 4.0–4.8

### Пуэр: generic-заготовки

Записи `sheng-pu-erh` и `shu-pu-erh` — категории, не отдельные продукты. При импорте предпочитать региональные и фабричные позиции.
