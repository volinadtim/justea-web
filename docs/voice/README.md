## Как проверялись цитаты

Все 27 цитат в `style-candidates.json` сверены дословно с первоисточником: тексты скачаны целиком (Project Gutenberg, Китайская Викитека, az.lib.ru), приведены к единой нормализации (HTML-сущности, кавычки, пробелы) и каждая цитата найдена в источнике подстрокой.

⚠️ Цитаты в `style-candidates.md` приведены по `az.lib.ru` и поэтому **потеряли типографику**: вместо «—» там `--`, вместо «ёлочек» — прямые кавычки. Для этапа 1 это не мешало (сравнивались манеры, не знаки), но для любой работы с пунктуацией нужны источники из [`punctuation.md`](./punctuation.md). Образцы в `prompts/probe/` уже взяты оттуда. Дата обращения — 2026-11-06 по заголовку HTTP `Date` (локальные часы машины спешат примерно на 20 минут).

Отдельно отмечено: в письме Чехова от 10 мая 1886 г. источник даёт «характер á propos» (acute), а не «à propos» — цитата приведена как в источнике.

## Правила генерации текстов (действуют с этапа 2)

1. Факты только из `docs/sources/catalog.json` (агент justea-sources). Ничего не выдумывать — ни ноты вкуса, ни температуры, ни историю сорта.
2. Если факта нет в каталоге — не писать его, а запросить у justea-sources через оркестратора.
3. Подражание стилю — да, копирование текстов — нет. В few-shot корпус идут только тексты в общественном достоянии; разбор по авторам — в `style-candidates.md`, раздел «Правовая рамка».
