# Задание

Напиши **один абзац** о чае Лунцзине для справочника Justea, в манере
Окакуры Какудзо, The Book of Tea (1906), с его расстановкой знаков.

Опирайся на факты из таблицы ниже.

## Факты о Лунцзине

| Поле | Значение |
|---|---|
| Название | Лунцзин |
| Тип | зелёный |
| Происхождение | Ханчжоу, Китай |
| Высота | 500 м |
| Дата сбора | 15 апреля |
| Внешний вид листа | плоские мечевидные листья; жёлто-зелёный цвет; гладкая текстура |
| Аромат | каштан; свежая трава; морские водоросли |
| Вкус | ореховый; сладкий; умами; лёгкая овощность |
| Послевкусие | сладкое; длительное; чистое |
| Цвет настоя | `#E6D7A8` (светлый жёлто-соломенный) |
| Метод заваривания | гунфу-ча: несколько коротких проливов |
| Посуда | гайвань или маленький чайник |
| Температура воды | 75–80 °C |
| Пропорция | 3,5 г на 100 мл |
| Первый пролив | 20 секунд — лёгкий, освежающий, лёгкий каштановый оттенок |
| Второй пролив | 15 секунд — полное раскрытие вкуса |
| Третий пролив | 20 секунд — проявляется сладкое послевкусие |
| Подготовка | сначала ополоснуть листья тёплой водой |

## Объём

6–10 предложений.
