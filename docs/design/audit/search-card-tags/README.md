# Теги в карточке поиска: до и после

Снято в модалке поиска по запросу «хун», карточка Да Хун Пао. Desktop 1440
и mobile 390, светлая и тёмная тема.

| | Светлая | Тёмная |
|---|---|---|
| **До**, desktop | `before-desktop-light.png` | `before-desktop-dark.png` |
| **После**, desktop | `after-desktop-light.png` | `after-desktop-dark.png` |
| **До**, mobile | `before-mobile-light.png` | `before-mobile-dark.png` |
| **После**, mobile | `after-mobile-light.png` | `after-mobile-dark.png` |

До: «Древесный, Пряный, Жареный, Тёмный шоколад» — четыре аромата, вкус
не показан вообще.
После: «Древесный, Пряный, Минеральный, Карамельный» — два аромата и два
вкуса.

Оформление тегов, их число, размеры и цвета не менялись — меняется только
то, какие четыре значения отбираются.

Из 24 записей каталога карточка меняется у восьми: у шести из-за четырёх
ароматов (Те Гуань Инь, Да Хун Пао, Би Ло Чунь, Бай Хао Инь Чжэнь, сенча,
дарджилинг) и ещё у двух, где ароматов три, а вкусов четыре (лунцзин,
ассам) — там вкус был виден одним значением из четырёх. У остальных
шестнадцати набор прежний.
