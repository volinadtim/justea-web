# Разделитель дробной части: до и после

Снято на `/longjing`, строка навески. Desktop 1440 и mobile 390, светлая
и тёмная тема.

| | Светлая | Тёмная |
|---|---|---|
| **До**, desktop | `before-desktop-light.png` | `before-desktop-dark.png` |
| **После**, desktop | `after-desktop-light.png` | `after-desktop-dark.png` |
| **До**, mobile | `before-mobile-light.png` | `before-mobile-dark.png` |
| **После**, mobile | `after-mobile-light.png` | `after-mobile-dark.png` |

Было «3.5 гр на 100 мл», стало «3,5 гр на 100 мл». Больше ничего:
шрифт, размер, цвет и положение те же.

Число пересчитывается при смене объёма, поэтому точка вылезала не только
на значении из данных: 2.4, 7.0, 17.5 и так далее.
