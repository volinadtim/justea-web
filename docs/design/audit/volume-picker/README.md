# Выбор объёма воды: до и после

Снято на `/longjing`: курсор поставлен в поле объёма, список открыт.
Desktop 1440 и mobile 390, светлая и тёмная тема.

| | Светлая | Тёмная |
|---|---|---|
| **До**, desktop | `before-desktop-light.png` | `before-desktop-dark.png` |
| **После**, desktop | `after-desktop-light.png` | `after-desktop-dark.png` |
| **До**, mobile | `before-mobile-light.png` | `before-mobile-dark.png` |
| **После**, mobile | `after-mobile-light.png` | `after-mobile-dark.png` |

На кадрах «до» строка разъезжается: поле «100» уезжает вверх отдельной
строкой, и на своём месте остаётся «3.5 гр на … мл» с дырой посередине.
На кадрах «после» «100» остаётся в строке.

Сам список выглядит одинаково: подложка, скругление и подсветка выбранного
пункта те же, что на master. В тёмной теме пункты по-прежнему читаются плохо
(белый текст на светло-зелёном, контраст 1,1) — это цвет, и чинится он
в PR #7 вместе с остальной палитрой.

Перенос «гр на» на две строки в узкой колонке есть и до, и после: он к этой
правке отношения не имеет.
