# Почему здесь нет скриншотов «до/после»

Все три правки этой ветки на экране не видны, и пара одинаковых кадров
ничего бы не показала:

- **h3 → h2** у заголовков «Аромат», «Вкус», «Послевкусие» — классы размера
  те же самые, меняется только тег. Проверяется деревом заголовков, а не
  глазами: было 1 → 3 с пропущенной ступенью, стало 1 → 2.
- **Токены `--font-geist` и `--font-mono`** в `globals.css` ни к одному
  элементу не применялись: `grep` по `font-geist` и `font-mono` в `app/`
  и `lib/` пустой. Эффект — минус две загрузки шрифта на страницу,
  вида это не касается.
- **`og.jpg`** на сайте не показывается вообще: это картинка для превью
  ссылки в соцсетях. Было 1200×800, стало 1200×630 — размер, который ждут
  Telegram, VK и остальные; раньше каждая обрезала его по-своему. Та же
  фотография, кадрирование по центру, ничего не дорисовано. Исходник
  и скрипт — в `docs/design/og/`.

Четвёртая правка, `FavoriteButton` на `useSyncExternalStore`, — замена
механики хранения. Сердечко выглядит и ведёт себя так же; размеры кнопки
оставлены как на master.
