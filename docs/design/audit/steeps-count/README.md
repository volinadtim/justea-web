# Нумерация проливов: до и после

Снято на `/longjing`, которому для проверки временно прописали девять проливов
(в коммит эта правка данных не входит). Блок проливов, desktop 1440 и mobile 390,
светлая и тёмная тема.

| | Светлая | Тёмная |
|---|---|---|
| **До**, desktop | `before-desktop-light.png` | `before-desktop-dark.png` |
| **После**, desktop | `after-desktop-light.png` | `after-desktop-dark.png` |
| **До**, mobile | `before-mobile-light.png` | `before-mobile-dark.png` |
| **После**, mobile | `after-mobile-light.png` | `after-mobile-dark.png` |

На кадрах «до» у седьмого, восьмого и девятого пролива есть время, но нет номера:
массив иероглифов кончался на шестом. На кадрах «после» пронумерованы все.
