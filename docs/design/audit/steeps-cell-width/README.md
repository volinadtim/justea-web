# Ячейка пролива: до и после

## Что проверялось в первую очередь — что для нынешних чаёв ничего не изменилось

`before-*` и `after-*` сняты на `/longjing` (каталог из 24 записей, master `241f0cf`) (три пролива, двузначное время),
кадр привязан к иконке решётки, рамка одинаковая. Сравнение побайтное:

| Кадр | Результат |
|---|---|
| desktop 1440, светлая | идентичен побайтно |
| desktop 1440, тёмная | идентичен побайтно |
| mobile 390, светлая | различается на 288 пикселей из 216 000 (0,13 %) |
| mobile 390, тёмная | различается на 278 пикселей из 216 000 (0,13 %) |

**Координаты и размеры всех ячеек совпадают**, колонки те же 26 px (29 px
на desktop), отступы те же. Расхождение на мобильном — сглаживание на краях
цифр: ячейка теперь растянута на ширину колонки (26 px) вместо прежних 22 px
с полем по 2 px, центр у текста тот же, но субпиксельная отрисовка краёв
чуть другая. Максимальное отличие по яркости — 47 из 255 на отдельных
пикселях контура.

Честно: это не «ни на пиксель». Это «ни на пиксель по геометрии и
на desktop, и сглаживание цифр на мобильном». Варианты, если и это не
подходит, — в описании PR.
