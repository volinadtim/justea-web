# Таймер проливов: до и после

Снято на `/assam` — у него западный стиль с одним проливом в четыре минуты,
то есть ровно тот случай, где подпись «сек» была неверной. Desktop 1440
и mobile 390, светлая и тёмная тема.

| | Светлая | Тёмная |
|---|---|---|
| **До**, desktop | `before-desktop-light.png` | `before-desktop-dark.png` |
| **После**, desktop | `after-desktop-light.png` | `after-desktop-dark.png` |
| **До**, mobile | `before-mobile-light.png` | `before-mobile-dark.png` |
| **После**, mobile | `after-mobile-light.png` | `after-mobile-dark.png` |

Видимых отличий два: «4:00 сек» стало «4:00 мин», и рядом со «Старт» появился
переключатель звука — та же круглая кнопка того же размера, что и остальные
кнопки таймера. Размеры карточки, отступы, цвета и шрифты не менялись.

Звук, вибрацию и Wake Lock на снимке не показать: они проверялись вручную
в браузере.
