## 1. Страница чая (`tea-page-mockup.png`)

Макет детальной страницы конкретного сорта. Пример: **Да Хун Пао**.

### Общий layout

```
┌─────────────┬──────────────────────────┬─────────────┐
│  Реклама    │     Контент (~670px)     │  Реклама    │
│  (серый     │                          │  (серый     │
│   блок)     │                          │   блок)     │
└─────────────┴──────────────────────────┴─────────────┘
```

- Фон страницы: фирменный зелёный `#9cd37a` (`--color-main`)
- Центральная колонка — основной контент
- Боковые колонки — плейсхолдеры рекламы (серые прямоугольники)
- Соответствует `AdvertisementContainer` в коде

### Блоки сверху вниз

#### Поиск

- Иконка лупы + поле ввода
- Нижняя граница (`border-b`) на всю ширину контента
- Компонент: `Search`

#### Тип чая

- Иконка листа + название категории («Пуэр»)
- Кликабельная ссылка на каталог по типу (пока не реализовано)
- Компонент: `TeaTypeLink`

#### Название чая

- Крупный заголовок — уровень **«Название»** в типографике
- Пример: «Да Хун Пао»

#### Аромат и вкус

Две колонки с дескрипторами:

| Поле | Пример |
|------|--------|
| **Аромат** | дым, влажный камень или пепел, орхидея, сладкие фрукты |
| **Вкус** | плотный, маслянистый, с нотами жжёного сахара, сухофруктов, земли |

- Компоненты: `TeaDescription`, `TeaDescriptionBlock`

#### Заголовок секции заваривания

- Текст: «Как заваривать проливами»
- Уровень **«Заголовок»**
- Стрелка вниз — намёк на раскрывающийся блок / переключение метода (в макете не раскрыт)

#### Параметры заваривания (левая колонка)

| Параметр | Иконка | Пример | Компонент |
|----------|--------|--------|-----------|
| Температура | термометр | 50–60 °C | `BrewTemperature` |
| Пропорция | весы | 5 гр на 100 мл | `BrewRatio` |

- Числа выделены шрифтом **Comfortaa** (bold)
- Подсказка-стрелка: «можно менять :)» — объём воды редактируется через `VolumeSelect`
- Компонент-обёртка: `BrewInfo`

#### Таблица проливов (правая колонка)

Две строки в сетке:

1. **Номер пролива** — иконка `#`, значения: 一 二 三 四 五 六 (китайские цифры)
2. **Время** — иконка таймера, значения в секундах: 5, 10, 20, 50, 75, 100

- Ширина ячейки: ~29px, gap между ячейками: 16px, gap между строками: 33px
- Компоненты: `SteepsTable`, `SteepsTableRow`

#### Нижний блок

- Широкий серый прямоугольник — плейсхолдер (фото чая, доп. контент или реклама)
- Компонент: `RowAdvertisement`

### Заметки по макету

- В блоке «Аромат» есть черновой текст-заглушка — убрать при наполнении данными
- Тип «Пуэр» для Да Хун Пао — скорее ошибка в примере (ДХП — улун); в данных использовать корректный `TeaType`
- Температура 50–60 °C — диапазон; в коде `BrewTemperature` для диапазона нужно показывать `from–to`, а не разность

### Соответствие коду

| Макет | Файл |
|-------|------|
| Страница | `app/[slug]/page.tsx` |
| Layout с рекламой | `app/layout.tsx`, `AdvertisementContainer` |
| Стили | `app/globals.css` |

## 2. Типографика и компоненты (`typography-and-components.png`)

Справочник по шрифтам и переиспользуемым UI-элементам.

### Шрифты

Основной шрифт интерфейса — **Bainsley** (локальный, `app/fonts/Bainsley/`).

Числа и акценты — **Comfortaa** (`font-comfortaa`).

| Уровень | Назначение | Пример использования |
|---------|------------|----------------------|
| **Название** | Главный заголовок страницы | «Да Хун Пао» — `text-[50px]` |
| **Заголовок** | Секции | «Как заваривать проливами» — `text-[37px]` |
| **Подзаголовок** | Подсекции, метки блоков | «Аромат», «Вкус» |
| **Тип чая** | Категория в навигации | «Пуэр» — `text-[22px]` |
| **Обычный текст** | Основной контент | дескрипторы аромата/вкуса — `text-base` (19px) |
| **Служебный текст** | Подписи, единицы | «сек», «гр», «мл» — `text-sm` (14px) |

Цифры (0–9) в макете показаны отдельно — для проливов и калькулятора пропорций используется **Comfortaa bold**.

### Компонент: таблица проливов

Три варианта нумерации проливов (выбран один — китайские цифры):

| Вариант | Проливы 1–6 |
|---------|-------------|
| Арабские | 1, 2, 3, 4, 5, 6 |
| Китайские | 一, 二, 三, 四, 五, 六 |
| Римские | I, II, III, IV, V, VI |

Времена проливов (одинаковые для всех вариантов):

`5 сек` → `10 сек` → `20 сек` → `50 сек` → `75 сек` → `100 сек`

#### Анатомия компонента

```
#  [一] [二] [三] [四] [五] [六]     ← строка номеров (HashIcon)
⏱  [5]  [10] [20] [50] [75] [100]   ← строка времён (TimerIcon)
      сек  сек  сек  сек  сек  сек    ← служебный текст под числом
```

- Иконка слева, значения в ряд с фиксированной шириной ячейки
- Числа времени — Comfortaa bold, 19px
- «сек» — 14px, по центру под числом

#### Реализация в коде

- `SteepsTable` — контейнер, массив `STEEP_NUMBERS` с китайскими цифрами
- `SteepsTableRow` — универсальная строка (иконка + значения)
- Переключение стиля нумерации — **не реализовано**, заложить как настройку или prop

### Цвета

| Токен | Значение | Где |
|-------|----------|-----|
| `--color-main` | `#9cd37a` | фон страницы |
| `--color-main-500` | `#7db95c` | блоки рекламы (заглушки) |
| Текст | `#000000` | основной |
| Плейсхолдеры | серый | реклама, нижний блок |
