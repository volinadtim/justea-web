# Чем собрана галерея

Порядок: `shoot.mjs` → `assemble.py` → `gen_index.py`. Нужен Node с playwright
(`npm i playwright && npx playwright install chromium`) и python3.

| Файл | Что делает |
|---|---|
| `sites.json` | список сайтов: адрес главной, адрес ключевой страницы и что это за страница |
| `shoot.mjs` | снимает главную и ключевую страницу в desktop 1440×900 и mobile 390×844, пишет статус, заголовок `Date` и причину отказа в `new/_shots.json`. Баннеры согласия закрывает **только отказом** — ничего не принимает |
| `assemble.py` | раскладывает снимки по папкам сайтов и собирает `_report.json`; кадры, которые сайт не отдал, помечает причиной |
| `gen_index.py` | собирает `index.html` из `_report.json` и `_works/_works.json`; стиль страницы — `gallery.css` |
| `works_pick.mjs`, `works_merge.py` | забирают картинки со страницы дизайнерской работы и дописывают их в `_works.json` |

Даты в карточках — из заголовка `Date` ответа самого сайта, то есть по его часам.
