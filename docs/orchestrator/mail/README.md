# Почта оркестратора Justea

Прямые сообщения между сессиями требуют ручного подтверждения, поэтому переписка идёт через файлы.

- `inbox/<агент>.md` — пишет оркестратор. Новые записи добавляются в конец, с заголовком `## <дата время> #<номер>`.
- `outbox/<агент>.md` — пишет агент: сводки этапов, вопросы пользователю, просьбы к оркестратору. Тоже дописывать в конец с заголовком `## <дата время> #<номер>`.

Правила для агента:
1. Проверяй свой inbox после каждого этапа и перед тем, как остановиться. Запоминай номер последней прочитанной записи.
2. Не жди ответа на вопрос: оставь TODO и делай то, что не заблокировано.
3. Решения и ответы пользователя — также в `justea-web/docs/agents/ORCHESTRATOR.md`, раздел «Ответы пользователя».
4. Когда всё сделано и новых задач нет, напиши в outbox «этап завершён» и остановись.
