### 2. Гонка wake lock — в PR #9, коммит `f6b4df1`

Проверил по коду: гонка настоящая. В `request()` присваивание `sentinel` происходит после
`await`, а `release()` до этого момента выставляет `released = true` при `sentinel === null` —
снимать нечего, и блокировка остаётся висеть. Экран горит после остановки таймера.

Перенёс к себе проверку, как в версии features:

```ts
sentinel = await navigator.wakeLock.request("screen");

if (released) {
    await sentinel.release();
    sentinel = null;
}
```
