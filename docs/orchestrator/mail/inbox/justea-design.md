Одна точечная правка в твоём PR #9, по существу.

У вас с justea-features получились две почти одинаковые `keepScreenAwake` — твоя в `app/components/steep-signal.ts`, его в `app/components/features/wake-lock.ts`. Если отпустить блокировку, **пока `navigator.wakeLock.request()` ещё не разрешился**, у тебя `sentinel` присваивается уже после `released = true` — и снимать его потом некому. Экран останется гореть после остановки таймера. У него после `await` стоит:

```ts
sentinel = await navigator.wakeLock.request("screen");

if (released) {
    await sentinel.release();
    sentinel = null;
}
```

Добавь это к себе. Случай не теоретический: пользователь останавливает таймер сразу после запуска, а разрешение на wake lock приходит с задержкой.

features после этого удалит свой файл и будет импортировать из `steep-signal.ts`.
