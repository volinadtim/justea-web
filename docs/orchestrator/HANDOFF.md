## Правила пользователя (обязательно)

1. **Интерфейс** — только точечные правки или строгие референсы пользователя.
   Разрешено: отклик, анимации, починка багов, поведение. Запрещено: менять вид —
   цвета, границы, размеры, раскладку.
2. **Тексты** — человеческие, без справочного аппарата. Аудитория и новичок, и
   мастер; ни тому, ни другому не нужны номера стандартов. Параметры заваривания
   (градусы, граммы, секунды) остаются: это продукт, а не справка.
3. **Пунктуация авторская, без «нейронной»** — длинных тире нет.
4. Мерж PR и выкат — только после «да» пользователя на конкретную правку.
5. Деньги, публикации, регистрации, письма людям — только после явного «да».
6. Пользователь говорит с оркестратором; оркестратор сам общается с агентами и
   приносит вопросы пачкой, по одной-две строки на агента с префиксом.

Полный список решений — `docs/agents/ORCHESTRATOR.md`, рабочие правила агентов —
`docs/agents/_common.md` (161 строка, почти все выведены из собственных ошибок).

## Решение, которого ждут

**Снимать ли 86 дескрипторов без источника.**

- 80 — измерение: у слов нет ни подтверждения про этот чай, ни нормативного
  термина, покрывающего этот тип чая.
- 6 — решение оркестратора: слова держатся на словарной статье (GB/T 14487), то
  есть словарь говорит, что слово существует, и ничего не говорит об этом чае.
- Число двигалось шесть раз, 60 → 67 → 70 → 77 → 78 → 80, и каждый шаг был
  снятием одного допущения, а не новой догадкой. Проход по источникам закончен,
  уменьшить его нечем.

**Что будет, если снять:** блок опустеет у девяти чаёв (лунцзин, ассам, Би Ло
Чунь, Бай Хао Инь Чжэнь, сенча, дарджилинг, гёкуро, ходзича, матча); всего без
характеристик станет 11 страниц из 24; у Те Гуань Инь и Да Хун Пао останется
по одному-два слова с объяснением; 11 чаёв не изменятся.

**Довод за снятие:** в тот же день мы отказались придумать характеристики Дянь
Хуну, потому что под них нет фактуры. Оставить 86 выдуманных у более известных
чаёв — двойной стандарт там, где он заметнее всего.

**Довод против:** это восемь самых известных страниц, и половина блоков на них
опустеет.

**Если пользователь скажет «только 80»** — у шести словарных слов не будет
никакого объяснения: единственная честная рамка звучала бы «никто не утверждал,
что этот чай освежающий», а такое на странице не ставят. Текста для этой ветки
не существует, и это надо сказать ему прямо.

**Снятие идёт одним выкатом** со снятием, двумя рамками и выписками источников.
Порознь нельзя: страница сначала опустеет, а объяснение придёт следующим.

происхождения. Выбросить, когда `characteristics` получит `sources` и

## Структурный долг: жанр значения

`characteristics` и `meta` не имеют `sources` и `confidence` — они есть только у
четырёх структур, где текст **утверждают**. За один вечер это стоило конкретного
четыре раза: рамка утверждала необоснованное; ответ потребовал ручной таблицы;
таблица переехала внутрь проверки; 21 дескриптор защищён только договорённостью.

**Задача seo:** `sources` и `confidence` у `characteristics` (на дескриптор, не на
блок) и у `meta.altitude`.

## Как продолжить на другой машине

```bash
git clone https://github.com/volinadtim/justea-web.git && cd justea-web
git checkout agent/orchestrator
pnpm install
```

Агентам — отдельные worktree на их ветках (`git worktree add ../justea-web-<имя>
agent/<имя>`), запускать вложенными сессиями с промптом:

«Ты — justea-<имя>. Прочитай `docs/agents/_common.md`, `docs/agents/<файл>.md`,
свою переписку `docs/orchestrator/mail/inbox/justea-<имя>.md` и
`outbox/justea-<имя>.md` (в ветке `agent/orchestrator`:
`git show origin/agent/orchestrator:<путь>`). Продолжай с места остановки.
Оркестратор — сессия Justea orchestrator.»

Пути в `_common.md` поправить под новую машину.

## Две вещи, на которых легко обжечься

1. **`data/teas.json` вне prettier** (`.prettierignore`), отступ 4. Конфиг
   расходится с репозиторием в 144 файлах, и любой `prettier --write .` перепишет
   всё. Правки скриптом писать с отступом 4, иначе дифф на четыре тысячи строк, и
   мерж после этого бьётся весь.
2. **Состояние ветки, прода и прогона называть по ним самим**, а не по памяти и
   не по разбору истории. За сутки на этом ошиблись четыре раза: «последний
   прогон» оказался предыдущим, «в master нет» — было, «текст у нас в файлах» —
   была сокращённая выписка с пропуском ровно в спорном месте.
