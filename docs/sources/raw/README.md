# `docs/sources/raw/` — выгрузки источников

Здесь лежат выгрузки источников, на которые опирается `docs/sources/catalog.json`.
Один файл = один источник. Формат каждого файла:

1. **Блок метаданных** (YAML-подобный список): `source_id`, уровень достоверности,
   издатель, URL, дата обращения, язык, лицензия/режим хранения.
2. **Что именно взято** — выдержки, числовые таблицы, определения.
3. **Замечания** — расхождения с другими источниками, оговорки, что в источнике
   отсутствует.

## Режимы хранения и копирайт

| Режим | Когда | Что лежит в репозитории |
|---|---|---|
| `full-text` | источник в общественном достоянии или под свободной лицензией | полный текст |
| `excerpt` | текст защищён копирайтом, но допустимо короткое цитирование | метаданные + короткие цитаты + числовые данные + ссылка |
| `metadata-only` | хранение текста недопустимо или текст недоступен | только метаданные и ссылка |

**Стандарты ISO и GB/T хранятся в режиме `excerpt`.** Документы ISO прямо помечены
`COPYRIGHT PROTECTED DOCUMENT`: воспроизведение и размещение в сети запрещено без
письменного разрешения ISO. Поэтому:

- PDF-файлы стандартов **не коммитятся** в репозиторий;
- берутся только область применения (одно-два предложения), определения терминов
  и числовые требования — как факты, с точной атрибуцией;
- для работы с полным текстом стандарт нужно купить у ISO или у национального
  органа по стандартизации.

Исходные PDF на время работы агента лежат вне репозитория:
`$CLAUDE_JOB_DIR/tmp/raw/`. Ссылки на официальные preview-страницы указаны в
каждом файле — по ним выгрузку можно воспроизвести.
