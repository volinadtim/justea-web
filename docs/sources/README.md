## Методика

### Уровни достоверности

Шкала задана в постановке задачи. Как она применялась на практике:

| Уровень | Что считается | Сколько в каталоге |
|---|---|---|
| **A** | стандарты (ISO, GB/T), госорганы, научные статьи в индексируемых журналах, исследовательские институты | **31** |
| **B** | отраслевые ассоциации общественной пользы, учебно-методические материалы отрасли, книги признанных авторов | **2** |
| **C** | магазины и блоги — только как подтверждение, никогда как первоисточник | **1** (сводный: существующие файлы проекта) |

### Правила, которые соблюдались

1. **У каждого факта — источник, дата обращения и язык.** Если источника нет,
   факт помечен `confidence: "none"` и остаётся в каталоге как «значение сайта,
   не подтверждено». Молча придумывать источник нельзя.
2. **Там, где источники расходятся — показан диапазон и объяснение**, а не
   произвольный выбор одного значения. Поле `disagreement` в `catalog.json`.
3. **Числовые факты отделены от оценочных.** Температура, навеска, время, границы
   географического указания — проверяемы. Вкусовые дескрипторы, рейтинг и hex цвета
   настоя — нет, и это сказано прямо.
4. **Назначение источника важнее его авторитетности.** ISO 3103 — стандарт высшего
   уровня, но он описывает дегустационное испытание, а не заваривание для питья, и
   прямо это оговаривает. Такие источники в каталоге помечены `purpose: "reference"`.
5. **Копирайт и robots.txt соблюдались.** Полные тексты стандартов не хранятся,
   антибот-защита не обходилась. Подробно — в [`raw/README.md`](./raw/README.md).
6. **Проверка ссылок — через открытые API**, не по памяти: Crossref REST API для
   DOI, NCBI E-utilities для PMC. Любую проверку можно повторить.
7. **Время в данных — с сервера.** Дата обращения взята из заголовка HTTP `Date`
   (2026-11-06T19:17Z), потому что локальные часы спешат примерно на 20 минут.

### Что проверялось отдельно

Перед тем как добавлять новое, проверено **существующее**: все 18 библиографических
ссылок в `docs/tea-brewing-science.md` и `-ru.md`. Все DOI и PMC-идентификаторы
оказались настоящими, но в 9 случаях неверно указаны авторы, журнал или год. Числовые
параметры заваривания при этом опираются на реальные исследования и в пересмотре не
нуждаются — исправить нужно список литературы. См. [`citation-audit.md`](./citation-audit.md).

## Главные содержательные находки

1. **ISO 3103 — не про заваривание чая для питья.** Прямая оговорка в стандарте.
   Если сайт будет ссылаться на него как на «правильный способ», это будет ошибкой.
2. **Потребительского стандарта гунфу не существует** ни в ISO, ни в GB/T, ни в JAS.
   Все числа вида «20 с, +5 с каждый пролив» — отраслевая практика. Ближайший
   нормативный аналог — метод оценки улуна по GB/T 23776: 5 г / 110 мл, проливы
   2/3/5 мин.
3. **`pu-erh` как тип расходится с обоими стандартами.** Шестой тип — тёмный чай,
   пуэр — его подтип, причём ISO относит к нему только шу. См. `schema-proposal.md`.
4. **У гёкуро навеска 16,7 г/100 мл** — в 7,5 раза больше, чем у обычной сенчи, при
   температуре 50 °C. Если заполнить его «по аналогии с зелёным чаем», получится
   грубая ошибка. Источник — префектура Сидзуока, уровень A.
5. **ISO 20716 нормативно описывает вкус улуна** — цветочный/фруктовый аромат,
   мягкий округлый вкус, сладкое послевкусие, прозрачный яркий настой. Единственный
   найденный случай, когда профиль типа чая закреплён стандартом.
6. **Аньцзи байча (安吉白茶, GB/T 20354) — зелёный чай**, несмотря на «白茶»
   (белый чай) в названии. Типичная ошибка каталогов.
7. **Китайское 红茶 = англоязычный black tea**, а 黑茶 («чёрный чай») — тёмный,
   постферментированный. Разные типы.
8. **ISO/TR 12591 сам содержит ошибку:** относит «longevity eyebrow» (寿眉, Шоу Мэй)
   к типу «только почка», что противоречит GB/T 22291 и практике. Зафиксировано как
   расхождение.
9. **В существующих ссылках 9 ошибок атрибуции** при настоящих DOI. См.
   `citation-audit.md`.
10. **«Чайного опьянения» (茶醉) в рецензируемой литературе нет.** Шесть
    целенаправленных запросов в PubMed и Crossref: ни одной работы о физиологии
    этого состояния. Единственное упоминание — анонимная заметка в *The Lancet*
    1901 года. См. `effects-caffeine-theanine.md`.
11. **Разброс теанина и кофеина внутри одного типа чая больше разницы между
    типами** (Csupor 2016, 37 образцов). Привычное «в зелёном чае больше теанина,
    чем в чёрном» этими данными не подтверждается. Единственное устойчивое
    отличие — в пуэре теанина практически нет.
12. **«Успокаивающий эффект» габа-улуна — гипотеза, не факт.** Обзор механизма
    (Hinton & Johnston 2020) прямо говорит: данных о прямом действии ГАМК из чая
    на мозг заметно меньше, чем о действии на периферические рецепторы.

## Воспроизводимость

Все выгрузки воспроизводимы по URL из `catalog.json` → `sources`. Скрипты сбора и
проверки на время работы агента лежат в `$CLAUDE_JOB_DIR/tmp/`:

| Скрипт | Что делает |
|---|---|
| `gbfetch.py`, `gbsearch2.py` | поиск по реестру стандартов КНР |
| `gbdetail.py`, `gbdetail2.py` | выгрузка карточек метаданных GB/T |
| `verify_refs.py`, `verify_refs2.py` | проверка DOI и PMC через Crossref и NCBI |
| `build_catalog.py` | сборка `catalog.json` |
| `pdftxt.py`, `htmltxt.py` | извлечение текста из PDF и HTML |

## Что осталось незакрытым

| Пробел | Почему |
|---|---|
| Параметры заваривания у 340 кандидатов | нужен отдельный этап; по 340 чаям это объём, несопоставимый с одним проходом |
| Источник у каждого факта кандидатов | то же |
| Полный текст GB/T 23776-2018 и GB/T 30766-2014 | система публичного доступа отдаёт только карточку; параметры взяты из вторичного источника (редакция 2009) и помечены `confidence: medium`. Для продакшна стандарты нужно купить |
| Assam GI, Nilgiri GI | регламенты Tea Board не выгружены (выгружен только Darjeeling) |
| Шри-Ланка, Тайвань | `srilankateaboard.lk` и `tbrs.gov.tw` не отвечают с обоих сетевых выходов (проверено 2026-11-06) |
| Theppakorn 2016 (*IFRJ*), Matsuda & Ozaki 1996 | нужна ручная проверка на сайтах журналов; IFRJ в Crossref индексируется неполно |
| Утверждение «жёсткая вода снижает катехины на 84–93 %» | источник не найден; в `catalog.json` не используется |
| 5 обновлённых GB/T вступают в силу 2027-10-01 | ссылки на редакции 2006–2008 станут устаревшими; в `catalog.json` есть поле `superseded_by` |
| Решения по `rating`, `liquorColor`, `pu-erh`/`dark` | ждут пользователя, см. `schema-proposal.md` |
