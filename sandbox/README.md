# sandbox

Песочница для экспериментов с вёрсткой страницы чая. Только HTML + CSS, без JS.
Фокус — мобильная версия (375–430 px).

## Структура

- `index.html` — список вариантов
- `shared/` — общее на все варианты: `styles.css` (несжатый бандл из `next dev`:
  Tailwind 4 + `next/font`), `fonts/` (woff2), `assets/` (картинки из `public/`)
- `base/` — копия текущей страницы `/longjing` как есть, референс
- `chinese-scroll-mobile/` — вариант 1 (заготовка)

Каждый вариант — папка со своим `index.html`, который тянет `../shared/styles.css`.

## Как смотреть

```bash
python3 -m http.server 3113 --directory sandbox
```

Дальше `http://localhost:3113/` → нужный вариант.
Тёмная тема: добавить `class="dark"` на `<html>`.

## Оговорка про CSS

В `shared/styles.css` лежат только те Tailwind-классы, что реально встречались
в компонентах сайта. Понадобится класс, которого на странице не было, —
дописать руками в конец файла или пересобрать снимок с dev-сервера.
